Projeto teste para demonstrar como usar Python para analisar uma base de Top 50 musicas no Spotify de 2019 e revelar os padrões que tornam uma música um sucesso.
Base de dados de 2019 obtida através do Kaggle.
Nesse exemplo exploramos métricas como BPM, energia, dançabilidade, volume e valência para entender as tendências das músicas mais tocadas em 2019 e ralizamos uma análise visual com gráfico de radar no Plotly, comparando médias e medianas para interpretar o que realmente define o sucesso de uma música.


Caso não esteja utilizando um ambiente como o Google Colab instale o Pandas e o Plotly em seu ambiente.
